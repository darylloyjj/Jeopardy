Quiz Show Challenge
An interactive Jeopardy-style quiz game designed for classrooms, parties, and team-building events. Its blue-and-gold theme and presentation-friendly layout make it easy to display on a large screen.

Features
Customizable game board: Six categories with five questions each.
Picture questions: Use text, uploaded images, or both, with optional answer images.
Team scoring: Support for 2–6 teams, manual score adjustments, and undo controls.
Presentation layouts: Three-screen presentation mode or a single-screen board with question overlays.
Host controls: Reveal answers, manage turns, mark responses, and reset gameplay.
Optional extras: Countdown timer and a Final Challenge with team wagers.
Editable content: Customize titles, categories, questions, answers, and point values.
Save and reuse: Browser-based saving and JSON import/export, including images where supported.
How to Play
Set up your teams, choose a category and point value, and answer the question. The host reveals the answer and awards or deducts points. Continue through the board, optionally play the Final Challenge, and finish with the highest score to win.

Note: Browser-saved content is specific to the device and browser used. Export your game to transfer customized questions and images to another computer.
